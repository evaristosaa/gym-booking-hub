# Gym Booking Hub Constitution

## Principles

1. **User credentials never leave the user's device.** The public web interface must not store, transmit, log, or commit passwords, cookies, tokens, or booking sessions.
2. **Pages is presentation, local agent is execution.** A static deployment may display and configure reservations; an opt-in user-owned agent performs bookings.
3. **No fake confirmations.** A booking is confirmed only after the target booking service reports success.
4. **Mobile first and accessible.** The agenda and errors must be clear on a phone without requiring a desktop.
5. **Portable by default.** The public interface must be deployable from a public static repository without personal infrastructure.
