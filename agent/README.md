# Agente local (pendiente)

Este directorio alojará el programa privado que ejecutará las reservas reales para cada persona.

Reglas innegociables:

- Las credenciales del proveedor viven solo en el dispositivo del usuario.
- El agente no se expone públicamente a Internet.
- Toda reserva debe informar un resultado verificable; no se simulan confirmaciones.
- El protocolo de emparejamiento con la interfaz web será explícito, revocable y sin secretos en URLs.
