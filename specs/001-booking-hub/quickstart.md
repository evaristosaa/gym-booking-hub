# Local Development Quickstart

1. Open `public/index.html` through a local static server.
2. Install it from Android Chrome using **Añadir a pantalla de inicio**.
3. Verify that plans survive browser reload and the UI remains compact on a phone.
4. Do **not** enter real WodBuster credentials until the backend vault and HTTPS deployment are implemented and reviewed.
5. When the backend exists, verify: connection validation, schedule creation, one controlled booking attempt, reservation reconciliation, and push notification delivery.
